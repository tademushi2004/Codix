# CODIX - ブラウザゲーム

脳科学「1000の脳理論」に基づく、クリーンアーキテクチャ・リアルタイムパズルゲーム。

## 概要

プレイヤーは自動移動するAIキャラクターを**配線（ワイヤリング）**で教育し、迷路内のオブジェクトの利害を学習させる。
観察→記憶→仮説構築→配線→検証のループを通じて、「1000の脳理論」における世界モデル構築をゲーム体験として再現する。

## 技術スタック

- **HTML5 Canvas** + **Vanilla JavaScript** + **CSS**
- 単一ファイル（`index.html`）デプロイ
- 外部ライブラリ不使用
